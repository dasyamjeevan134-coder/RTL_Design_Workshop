# 1. Case Statement

A `case` statement is commonly used in Verilog RTL design to describe
multiplexer and selection logic.

It selects one of several possible outputs based on the value of a
control or select signal.

A properly written case statement should cover all possible input
conditions when combinational logic is intended.

# 3. Incomplete If Statement

An incomplete `if` statement occurs when an output is not assigned
for every possible condition.

For combinational logic, this may cause the synthesis tool to infer
a latch because the output needs to retain its previous value when
the condition is not satisfied.

# 5. Multiplexer

A multiplexer (MUX) is a combinational circuit that selects one input
from multiple input signals and sends the selected signal to the
output.

The selection is controlled by one or more select lines.

Multiplexers are commonly described using `if`, `case`, or conditional
operator statements in Verilog.

# 7. Ripple Carry Adder

A Ripple Carry Adder (RCA) is a digital circuit used to add two binary
numbers.

It is constructed by connecting multiple full adders in series.
The carry output of one full adder becomes the carry input of the
next full adder.

The carry therefore propagates from the least significant bit toward
the most significant bit.

# 10. Latch Inference

One of the important concepts demonstrated in Day 5 is latch
inference.

A latch may be inferred when a combinational RTL block does not assign
a value to its output for every possible input condition.

For example, if an output is assigned only inside an `if` condition
and there is no `else` condition, the synthesis tool may need to
retain the previous value of the output.

This results in latch hardware.

To avoid unintended latches:

- Assign outputs for all possible conditions.
- Use complete `if-else` statements.
- Use complete `case` statements.
- Provide suitable default assignments.

---

# 11. Complete vs Incomplete RTL

| RTL Coding | Result |
|------------|--------|
| Complete `if-else` | Combinational logic |
| Incomplete `if` | May infer latch |
| Complete `case` | Combinational logic |
| Incomplete `case` | May infer latch |
| Proper default assignment | Helps avoid unintended latches |
